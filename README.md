## Selected projects

### [WorldGuard](https://github.com/Yu-han-Shu/WorldGuard) · Agent-assisted navigation evaluation

A workbench for testing indoor navigation policies, checking geometric constraints independently, and replaying failure–recovery evidence. I coordinated the team project, designed scenarios and tests, integrated the workbench, and organized the report and demo.

**Scope:** 2D single-robot simulation; no physical-robot validation. [Demo video](https://www.bilibili.com/video/BV1dQJ66tEsV/) · [Validation notes](https://github.com/Yu-han-Shu/WorldGuard/blob/main/docs/VALIDATION.md)

### [RealityScan UV-to-3D Navigation](https://github.com/Yu-han-Shu/realityscan-uv3d-navigation) · Graphics & geometry

Maps image coordinates into reconstructed 3D scenes and plans collision-aware paths through point clouds. The saved evaluation covers 25 navigation paths across five scenes, with no collision violations among 4,172 checked path points. These are results on the released test scenes, not a claim of real-world robot performance.

### [MathAgent Demo](https://github.com/Yu-han-Shu/mathagent_demo) · Mathematical reasoning

A minimal solver–verifier workflow combining LLM calls with local SymPy tools. Includes batch experiments, an experiment dashboard, structured logs, and offline reports; a runnable prototype with a small toy problem set.

### [Quant Factor Research Lab](https://github.com/Yu-han-Shu/quant-factor-research-lab) · Independent quantitative practice

A modular Python framework for factor evaluation, walk-forward validation, multiple-testing control, and transaction-cost-aware backtesting. The public demonstration uses simulated data to validate the workflow and generate reproducible reports.

### [CUMCM 2026: Localization & Search](https://yu-han-shu.github.io/#cumcm) · Mathematical modeling

Our team combined bounded-error localization, minimax robust optimization, sequential search, and rolling path planning for interference-source clearance. Awarded the Jiangsu Provincial First Prize; evaluated through simulation.
